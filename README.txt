Use AdGuard Home in your smart home:

- Enable/disable protection, or pause it for a number of minutes
- Turn filter lists, parental control, safe search, safe browsing and the query log on or off

- Block or always allow a domain, and add or remove custom filtering rules from your Flows
- Add, remove, enable or disable filter lists and refresh them
- Check whether a domain is blocked
- Use all of it in your Flows
